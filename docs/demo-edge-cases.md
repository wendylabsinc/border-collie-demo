# Demo edge-case inventory

This inventory follows the production sequence in
[`demo-sequence.md`](demo-sequence.md). It is a design and test checklist, not
evidence that every case has passed on Woof.

Status meanings:

- **Handled** — the current implementation has an explicit safe behavior and
  automated coverage.
- **Partial** — a guard or deterministic test exists, but physical qualification,
  complete evidence, or part of the documented behavior is still missing.
- **Gap** — the behavior is documented or desirable but is not wired into the
  current production path.

The test column distinguishes automated checks from supervised physical checks.
No automated replay qualifies motion in a real operating envelope.

## Highest-priority physical edge-case suite

Before broadening the fruit or room envelope, run these supervised cases with
**Stop Woof** and the physical remote immediately available:

1. Pear already visible, then pear initially out of view.
2. Red apple already visible, then initially out of view.
3. Off-center target on both sides, verifying no forward heartbeat before three
   centered samples.
4. Brief pre-near occlusion versus lower-edge disappearance after near geometry.
5. Small-area approach repeated enough to measure final fruit-distance spread.
6. Home return with independent floor markers, recording overshoot and heading
   error, especially the asymmetric 0.3 m/s final-push heartbeat replay.
